# Automatic Tooth–Gingiva Segmentation

## Overview

Automatic Tooth–Gingiva Segmentation is a Python-based application that automatically separates teeth and gums from a 3D dental model. The project is designed to reduce manual editing by identifying the boundary between teeth and gingiva and generating separate meshes for further analysis or processing.

This project is suitable for dental CAD workflows, research, educational purposes, and preprocessing of intraoral scan data.

---

## Workflow

1. Load a 3D dental mesh.
2. Preprocess the mesh.
3. Detect the tooth–gingiva boundary.
4. Segment the model.
5. Generate separate tooth and gingiva meshes.
6. Visualize the results.
7. Export the segmented models.
